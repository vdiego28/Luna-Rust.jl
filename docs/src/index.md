# Amalthea.jl Documentation
This is the documentation for [Amalthea.jl](https://github.com/vdiego28/Amalthea.jl), a performance-engineering fork of [Luna.jl](https://github.com/LupoLab/Luna.jl) that adds a native Rust numerical backend. Start with [Installation and configuration](installation.md) for Linux, macOS, Windows, ARM64, CPU-only, source-build, and optional CUDA instructions. The [README](https://github.com/vdiego28/Amalthea.jl/blob/main/README.md) contains the shorter quickstart and a reproducible Julia-oracle/native performance comparison, including a current workload where the native path is not faster. This documentation is intended to lay out the physical model used and give deeper insight into the workings of Amalthea.jl. It is not yet complete--any contributions are welcome!

If you are new to Amalthea.jl, the most interesting page is probably [the simple interface](#The-simple-interface). Details about the actual equation Amalthea.jl solves can be found in [the numerical model](#The-numerical-model) section.
